# Power BI Build Specification

Recommended pages:

1. **Executive Control Tower** — FX risk, labor benchmark and talent-demand trend.
2. **FX Exposure** — currency trend, 30-day volatility and risk flag.
3. **Labor Economics** — India city salary trend and USD-normalized view.
4. **Talent Demand** — role-family demand, geography and compensation.

Do not add invented targets or budgets. Clearly label forecasts and scenarios as model outputs.
