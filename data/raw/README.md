# Raw public-source data

Place the supplied public source archives in `data/raw/archives/`.

The application reads the CSVs directly from ZIP archives and does not require manual extraction.

Required archives:
- exchange_rate_to_usd.csv.zip
- exchange_rate_usd_to.csv.zip
- india_col_salary_longitudinal_2010_2024.csv.zip
- linkedin_role_market_extract.csv.zip
- linkedin_supporting_tables.zip

The full LinkedIn postings archive belongs in a GitHub Release rather than ordinary Git.
