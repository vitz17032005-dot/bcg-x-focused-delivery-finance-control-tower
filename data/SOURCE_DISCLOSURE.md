# Public Data Disclosure

All source records used by this project come from public datasets supplied by the user. No BCG internal or proprietary data is used.

The complete LinkedIn `postings.csv` source is too large for ordinary Git. The repository uses a source-derived technology-role extract plus compressed supporting public source archives. The extract is not a newly collected dataset and does not contain fabricated rows.

Any benchmark, proxy, forecast or scenario is derived and must be labeled as such.
